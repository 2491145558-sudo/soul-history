# 测测你的灵魂对应哪位中国历史人物

解压后双击 index.html 即可使用。三个文件 index.html、style.css、app.js 需保持在同一文件夹。无需后端、安装或联网；也可将它们部署到任意静态网站空间。

功能：40道单选题、逐题前进与返回、八维画像、14个人物结果、自动保存本机进度、答案回看、重新测试、PNG分享卡片导出、响应式布局、键盘操作和减少动画支持。选择后点击“下一题”继续，避免误触跳题。

评分：8维分别为规划、社交、探索、共情、主导、审美、原则、长期倾向；每维5题，每题4项分别记 -3/-1/+1/+3 分。各维取平均值，以与人物原型向量的等权欧氏距离匹配；距离相同按结果预设顺序决定。评分无随机项、没有优劣排名，光谱位置不是人群百分位或心理量表分数。

人物共14位：诸葛亮、张良、李世民、刘邦、苏轼、王阳明、李白、杜甫、辛弃疾、荆轲、韩信、岳飞、陶渊明、林逋。谋士、帝王、文人、诗人、侠客气质、将领、隐士各2种；类别为趣味原型，例如辛弃疾的“侠客气质”不是历史职业判定。专属文案为原创，不是人物原话。人物形象为文化印象的局部映射，不是史学评价或专业心理诊断。

隐私：答卷仅保存在当前浏览器的 localStorage，未向服务器发送。浏览器禁止存储时仍可答题，但无法跨刷新恢复。重新测试会清除当前答卷；首页“启卷”开始新答卷，“继续上次的答卷”恢复旧答卷。结果可截图或通过原生Canvas导出简洁分享卡片。下载行为取决于浏览器设置。

源代码说明：index.html 为页面结构，style.css 为视觉与响应式样式，app.js 含40题完整文案、14个人物内容、纯函数评分与交互。无第三方依赖与外部素材。
